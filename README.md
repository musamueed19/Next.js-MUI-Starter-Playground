# Next.js + MUI Integration Playground  

This project is a simple learning playground to practice integrating **Material UI (MUI)** with **Next.js**.  

## 🚀 Tech Stack  
- [Next.js](https://nextjs.org/) – React Framework for SSR & SSG  
- [Material UI (MUI)](https://mui.com/) – React UI Component Library  
- [Emotion](https://emotion.sh/docs/introduction) – CSS-in-JS styling engine  

## 📦 Installation  

```bash
# Clone the repo
git clone https://github.com/<your-username>/nextjs-mui-playground.git
cd nextjs-mui-playground

# Install dependencies
npm install

# Run the development server
npm run dev
